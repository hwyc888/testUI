# 校园招生管理系统

一个面向学校招生工作的响应式前端演示项目，包含数据总览、学生报名、报名审核、专业管理、数据统计和系统设置页面。

## 在线预览

部署到 GitHub Pages 后访问：

https://hwyc888.github.io/testUI/

## 本地预览

本项目为纯静态网页，不需要安装依赖。可直接打开 index.html，也可以在项目目录启动任意静态文件服务器。

## 功能说明

- 招生数据总览、报名趋势与专业计划进度
- 学生报名列表、关键词搜索、状态筛选和分页
- 新增报名、报名详情、审核通过与退回
- CSV 名单导出
- 专业招生计划展示、数据统计和系统设置示例
- PC、平板与手机响应式布局

## 技术说明

- HTML、CSS、原生 JavaScript
- 无第三方运行时依赖
- 演示数据保存在浏览器页面运行内存中，刷新后恢复初始样例
- 当前版本是前端演示，不包含真实账号认证、服务端 API 或数据库；正式投入使用前需要接入学校业务后台并完善权限、审计和个人信息保护措施

## 发布

项目通过 GitHub Actions 自动部署到 GitHub Pages。推送到 main 分支后触发发布流程。
